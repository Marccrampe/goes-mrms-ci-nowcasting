This notebook uses direct raw.githubusercontent.com image links, not notebook

session directory. An old clone from a previous run is never reused.

After committing, reopen the notebook through the README Colab button and run
the new first code cell. An already open Colab tab may still contain old code:
reopen the GitHub notebook, not just its old runtime.

The case data are small ordinary repository files. If they were committed as
Git LFS pointers rather than actual NPZ files, setup explicitly reports that.

Local validation: all cells compile; bootstrap tested with a simulated fresh
Git checkout; archived case checksums/classifications still reproduce.
